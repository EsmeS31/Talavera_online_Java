# Overview

Talavera Online is a responsive storefront prototype for a small business that could sell traditional, hand-painted Talavera ceramics from Puebla, Mexico in the United States. The site presents a product catalog with placeholder products while the business gathers real product names, images, and prices.

I created this project to strengthen my understanding of client-side JavaScript and how it can make a website interactive. The software demonstrates JavaScript through a mobile navigation menu, a product carousel, product search, category filters, and a contact form with basic validation.

My purpose for writing this software was to practice JavaScript syntax in a realistic project. I learned how to store values in variables, write functions, use `if` statements and `for` loops, respond to user events, and use the Document Object Model (DOM) to change what users see on the page.

The product carousel changes the featured product when the user selects the Previous or Next button. The catalog allows users to search for products and filter them by category. The contact form checks that the name, email, and message fields are completed before showing a response.

# Development Environment

The website was developed with a code editor and tested in a web browser. The project files are organized into an HTML file for the page structure, a CSS file for the visual design and responsive layout, and a JavaScript file for interactive behavior.

The software uses HTML, CSS, and vanilla JavaScript. No JavaScript libraries or frameworks were used. The project uses the browser's built-in DOM API, including methods such as `querySelector()`, `getElementById()`, `classList`, and `addEventListener()`.
